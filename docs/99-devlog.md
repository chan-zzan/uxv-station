# 개발 일지

> 그날 무슨 일이 있었고 뭐에 막혔는지를 남긴다.
> 나중에 케이스 스터디와 면접 답변의 원재료가 되는 기록.

## 작성 규칙

**분량: 한 항목당 5~7줄, 5분 안에.**
평일 저녁 1시간 작업인데 일지에 15분 쓰면 배보다 배꼽이다. 길게 쓰고 싶어지면 그건 ADR감이다.

- **`한 줄 요약`은 필수.** 진전이 없었던 날도 그대로 한 줄로 적는다.
- 나머지 항목은 각 1~2줄. 없으면 생략한다.
- 날짜는 **작업 시작일** 기준. 밤 작업이 자정을 넘겨도 시작일로 적는다.
- 결정 내용을 길게 쓰지 않는다. `docs/decisions/`에 ADR로 남기고 여기선 링크만 건다.
  (일지가 ADR과 겹치기 시작하면 둘 다 부실해진다)

### 다른 기록 수단과의 역할 분담

| | 담는 것 |
|---|---|
| `git log` | 무엇이 바뀌었나 |
| `docs/decisions/` | **왜** 그렇게 결정했나 |
| **이 문서** | 그날 무슨 일이 있었나, 뭐에 막혔나 |

### ⚠️ 보안

**이 저장소는 공개다. 일지도 같이 공개된다.**
"회사에서 하던 방식대로 해보니…" 같은 문장이 일지에는 가장 자연스럽게 새어 나온다.
실무 프로젝트·실제 장비 명칭·군 제원·실 통신 규격을 언급하지 않는다.
([uxv-station-roadmap.md](uxv-station-roadmap.md) 3장)

## Day 2 — 2026-07-27 (월) · 약 2시간

**한 줄 요약**: 계약을 JSON까지 확정하고, 스텁의 원운동(`position`)까지 짰다.

- **한 것** — 환경 확인(Node 24 LTS / Python 3.11.9). 계약을 개념 수준에서 실제 JSON으로 확정, ADR 0002·0003 작성.
  `uxv-stub` venv 구성 후 `make_state(t)` 작성 — 시각 기반 원운동으로 `position`까지 나온다.
- **결정** — 좌표계 ENU([0002](decisions/0002-coordinate-frame.md)),
  전송 WebSocket 단일([0003](decisions/0003-websocket-only.md)),
  하트비트는 `VehicleState` 겸용(타임아웃 1초). AI 인라인 자동완성은 `.vscode/settings.json`으로 껐다.
- **막힌 것** — PowerShell 실행 정책이 `Activate.ps1`을 차단. `requirements.txt`에 한글 주석을 넣었더니
  pip이 cp949로 읽어 `UnicodeDecodeError` — 주석은 README로 옮기고 파일은 ASCII만 남겼다.
- **배운 것** — 설계 범위의 기준은 자세함이 아니라 **바꿀 때의 비용**.
  위치는 각도가 2π를 넘어도 cos/sin이 감아주지만 `yaw`는 그대로 새어나온다 → 정규화가 필요하다.
- **다음** — yaw 정규화 → `attitude`·`velocity`·`gimbal` → 10Hz 발행 루프.

## Day 3 — 2026-07-28 (화) · 약 1시간

**한 줄 요약**: `make_state`가 계약의 `VehicleState`를 전부 채웠다. A단계는 발행 루프만 남았다.

- **한 것** — `normalize_angle` 작성 후 `attitude`·`velocity`·`gimbal`·`mode`까지 채웠다.
  t=0/10/20/30 검산표(위치·yaw 방위·속력) 전부 통과. 운동 수식은 `calc_angle` 한 곳으로 모았다.
- **결정** — 계약의 `attitude` 범위를 축별로 분리(`pitch`만 `±π/2`), 자세 표현은 오일러각 유지
  ([0004](decisions/0004-euler-angles.md)).
- **막힌 것** — `normalize_angle` 첫 판을 **도(°) 입력·라디안 출력**으로 짜서 단위가 어긋났다.
  에러 없이 그럴듯한 숫자가 나와서 못 알아챘고, 멱등성 검사로 잡았다.
  `attitude`를 `altitude`(고도)로 오타 낸 것도 있었다.
- **배운 것** — 정규화 함수는 **멱등**해야 한다. 결과를 다시 넣어 값이 변하면 그 자리에 버그가 있다.
  그리고 JSON에는 스키마 검사가 없어서 필드명 오타가 양쪽 다 조용히 통과한다.
- **다음** — `publish_loop(send)`. `sleep(0.1)`은 드리프트가 쌓이므로 n번째 발행 시각을
  `시작시각 + n × 0.1`로 절대 계산한다.

## Day 4 — 2026-08-06 (목) · 약 1시간 30분

**한 줄 요약**: `publish_loop` 1판 완성. 스텁이 10Hz로 JSON을 뿜는다.

- **한 것** — `make_state`를 순수 함수로 되돌리고(`start_time`을 인자로),
  `publish_loop(send)` 작성. `json.dumps`까지. 첫 줄 검산 3종 통과
  (`timestamp` 17억대 / `position` (20, 0) / 큰따옴표).
- **결정** — 스텁 시간 모델은 경과 시간 기반. `t`는 0부터 시작하고 `timestamp`만 Unix 시각으로 만든다
  ([0005](decisions/0005-stub-time-model.md)).
- **막힌 것** — `time.time` 괄호 누락으로 함수 객체가 그대로 들어감.
  두 시계(`time()`/`monotonic()`)를 한 변수로 겸용해 `timestamp`가 깨짐. `dumps`를 `loads`로 씀.
- **배운 것** — 실측 10틱에 1.016초. `sleep(0.1)`은 1.6% 느리고 오차가 누적된다.
  윈도우 시계 해상도가 15.6ms라 간격이 0.094/0.109로 튄다.
- **다음** — 2판. 목표 시각을 `시작 + n×0.1`로 절대 계산.

## Day 5 — 2026-08-11 (화) · 약 1시간

**한 줄 요약**: `publish_loop` 2판. 드리프트를 없애고 스텁 A단계를 끝냈다.

- **한 것** — 목표 시각을 `루프시작 + n×0.1`로 절대 계산하도록 전환하고, `sleep`을 `send` 앞으로 옮겼다.
  40초 한 바퀴 검증 — 검산표(t=0/10/20/30/40) 통과, `yaw` 401개 전부 `-π ~ +π` 안.
- **결정** — `make_state`에 넘기는 `t`를 실측 경과가 아니라 목표 시각(`n × 0.1`)으로
  ([0005](decisions/0005-stub-time-model.md) 연장).
- **막힌 것** — 계산해둔 변수를 안 쓰는 실수를 세 번 반복(`skip_time`, `target_loop_time`).
  `max(0, ...)`가 음수 `sleep`을 0으로 만들어 "한 번도 안 자는" 버그를 조용히 숨겼다.
- **배운 것** — `timestamp`를 계산값으로 바꾸니 그걸로 타이밍을 못 재게 됐다. 실측은 밖에서
  `Measure-Command`로(100틱 10.049초). `timestamp`가 17억이라 float 정밀도가
  0.00000024초에서 끊긴다 — ROS2가 시간을 정수 두 개(`sec`/`nanosec`)로 싣는 이유.
- **다음** — 스텁 B단계는 브리지 이후. 작업 순서 [1]의 남은 절반, 웹 UI 착수.

  브리지 없이 렌더링이 서게 해서 버그 원인 후보를 여섯에서 하나로 줄인다
  ([04-web-structure.md](04-web-structure.md)).

## Day 8 — 2026-08-19 (수) · 약 1시간

**한 줄 요약**: 코드 진전 없음. 밀린 커밋을 푸시하고 React 실행 모델을 팠지만 **아직 완전히 이해하지 못했다.**

- **한 것** — 로컬에만 있던 커밋 4개 푸시. `MapCanvas.tsx`를 읽으며 `useRef`·`ref`·JSX·DOM의 관계를 정리했다.
- **막힌 것** — JSX가 HTML처럼 생겨서 "내가 쓴 것 / 변환된 JS / 실제 DOM" 셋이 겹쳐 보였다.
  `ref`가 왜 필요한지가 특히 안 잡혔고, **소화하지 못한 채로 끝냈다.**
  설명량이 많아 여러 번 끊고 되돌아갔다 — 한 응답에 개념 하나씩이 맞다.
- **배운 것** — 컴포넌트 함수는 매 프레임이 아니라 **리렌더될 때만** 실행된다.
  JSX는 프리팹, DOM 요소는 인스턴스. React가 `Instantiate`를 대신 하므로 그 결과를 받아둘 자리가 `ref`다.
- **다음** — `ref`/`useRef`를 다시 짚고 → `useEffect`와 렌더 루프 → `scaleRef` → W1 마무리 작업.
