# uxv-station

무인 차량 통합관제 데모 — 시뮬레이터 + 통신 브리지 + 웹 운용통제기.

웹 운용통제 UI에서 무인차량에 임무를 지시하고 상태를 감시한다.
차량은 시뮬레이터 안에서 실제 차량 기구학에 따라 자율주행하며,
짐벌 카메라는 차체 기동과 무관하게 지정 표적을 계속 조준한다.
통신이 끊기면 안전 동작으로 전환한다.

> 🚧 개발 중 — 현재 단계: **[1] 웹 UI + 스텁 퍼블리셔**

---

## v1 목표

지도에 웨이포인트를 찍으면 **A\***로 경로가 생성되고, 차량이 **Pure Pursuit**로
경로를 추종하며 주행한다(곡률 기반 감속 포함).
주행 중 화면에서 표적을 지정하면 **짐벌이 차체 기동과 무관하게 그 표적을 계속 조준**한다.
통신이 끊기면 **하트비트 타임아웃으로 안전 정지**한다.

## 구조

```
   웹 UI            브리지               시뮬레이터
┌──────────┐   ┌──────────────┐   ┌──────────────┐
│ React+TS │◀──│   FastAPI    │◀──│    UE5       │
│  canvas  │ WS│  (Python)    │TCP│  (C++ 중심)   │
└──────────┘──▶└──────────────┘──▶└──────────────┘

   ※ 현재는 UE5 자리에 스텁 퍼블리셔가 들어가 있다
```

| 디렉터리 | 내용 | 기술 |
|---|---|---|
| `uxv-web/` | 웹 운용통제 UI | React + TypeScript + Vite |
| `uxv-bridge-server/` | 통신 브리지 | Python + FastAPI (WebSocket) |
| `uxv-stub/` | 가짜 차량 퍼블리셔 | Python |
| `uxv-sim/` | 시뮬레이터 | UE5 (C++ 중심) |
